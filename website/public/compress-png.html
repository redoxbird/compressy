    Will transparency be preserved?

    Yes. Lossless keeps alpha bit-exact. Lossy/WebP keeps alpha where the target format supports it.

    Is PNG compression lossless by default?

    Toggle on → lossless (metadata only). Toggle off → allows more aggressive shrinking and optional WebP conversion.

    Do I need to upload?

    No. All PNG processing is local. No upload, no account.
