# Compressy SEO Page Strategy & URL Map

**Goal:** Build the organic-search footprint for Compressy around high-intent image compression, conversion, resizing, target-file-size, format-specific, platform-specific, and educational searches.

**Principle:** Prioritize pages that contain a real, useful tool or workflow. Avoid thin keyword-swapped pages. Each page should have a distinct search intent, unique copy, and a direct path to using Compressy.

## 15. Recommended information architecture

Keep the navigation simple while allowing search engines to discover the deeper pages through contextual internal links.

**Primary navigation:**

- Compress
- Convert
- Resize
- Guides
- Download

**Core hierarchy:**

- `/compress-*` → compression intent
- `/resize-*` → resizing intent
- `/*-to-*` → conversion intent
- `/guides/*` → educational intent
- `/windows-*` → desktop intent

## 16. Internal-linking strategy

Every tool page should link to closely related tools rather than generic pages only.

Example:

**`/compress-jpg`** → `/jpg-to-webp` → `/compress-webp` → `/compress-image-to-100kb` → `/compress-images-without-losing-quality` → `/windows-image-compressor`

**`/compress-png`** → `/png-to-webp` → `/compress-webp` → `/compress-image-to-500kb` → `/offline-image-compressor`

**`/windows-image-compressor`** → `/download` → `/batch-image-compressor-windows` → `/offline-image-compressor-windows`

Guides should link naturally to the tools they explain, and tool pages should link back to the relevant guides.

## 18. SEO rules for every generated page

1. **One primary search intent per URL.**
2. Put the actual Compressy tool near the top when relevant.
3. Give each page unique copy, examples, screenshots, and FAQs where useful.
4. Don't create pages solely by swapping a keyword into an identical template.
5. Don't index pages with no meaningful content or functionality.
6. Cross-link related formats, conversions, sizes, guides, and the Windows app.
7. Keep titles and descriptions written for users, not keyword stuffing.
8. Add structured data only when it genuinely matches the page content.
9. Track impressions, clicks, CTR, rankings, conversions, and tool usage per URL.
10. Consolidate or noindex pages that overlap heavily or fail to establish distinct search intent.

## 20. Important: validate before building at scale

This is a **strategic page map**, not a claim that every URL has enough search volume to deserve a dedicated indexed page. Before creating the full cluster, validate keywords using Google Search Console once traffic exists plus a keyword dataset/tool, then prioritize by search intent, difficulty, business value, and overlap.

The best long-term strategy for Compressy is to combine **real browser tools + Windows software + genuinely useful SEO pages**, rather than publishing hundreds of near-identical landing pages.
