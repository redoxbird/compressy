    Is my image ever sent to a server?

    No. Compression runs entirely on your PC. No image is uploaded, no server sees it, no copy is stored remotely.

    Can I uninstall and be sure nothing remains?

    Yes. Compressy writes only local output files you choose. No cloud copy, no residue on a server.

    Does it work with no internet?

    Yes. Once installed, compression is fully offline — private even on an air-gapped machine.

    Is batch compression private too?

    Yes. A batch folder is processed locally file-by-file; nothing is aggregated or uploaded.
