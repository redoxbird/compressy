2 December 2024 · Windows 10 / 11 · 64-bit · Signed installer
18.2 MB installer · 16.8 MB portable
Changelog
Added
  • Auto-rename on export — {prefix}-{NNNN}.{ext} with live preview in settings — e.g. photo-0001.jpg
  • Max width / max height resize — downscale only, keeps aspect, per-file savings badge reflects resized dimensions
  • CSV export now includes renamed column and output dimensions
Improved
  • Settings panel — single caption column (Options / Resize / Rename), 2×2 options grid, unified disabled states
  • Results list — flex columns replace stacked br layout; savings badge widened so −27% · −904 KB never clips
  • Header metrics and status bar now wrap instead of overflow on narrow windows
Fixed
  • Inline style drift in Quality label and backup .bak hint — moved to token classes
  • Focus-visible rings and ARIA live regions for file counts and compression progress

  • ✓ Offline — no internet required after install
  • ✓ Signed installer (Authenticode) — SmartScreen-friendly
