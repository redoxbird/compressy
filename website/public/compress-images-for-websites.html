WebP vs AVIF for web?

WebP is the safe default — universal modern and 30% smaller than JPG. AVIF is 50% smaller but slower to encode; use for hero images where bytes matter most.

Will this help Core Web Vitals?

Yes. Smaller images improve LCP and reduce layout shift when you keep dimensions. Compress before upload, keep responsive sizes.

Can I batch a whole site?

Yes. Drop the site folder, Compressy finds images in subfolders, keeps structure, writes WebP/AVIF alongside.
