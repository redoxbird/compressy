    Is JPEG the same as JPG?

    Yes. JPG and JPEG are the same format — different extension, same mozjpeg engine. This page and /compress-jpeg do the same thing.

    What quality should I use for JPG?

    85 is the default — 57.8% avg saved, 92.4% peak on 456 files. Use 80 for more savings (~60%), 90 for fidelity (~40%).

    Can I convert JPG to WebP at the same time?

    Yes. Set output to WebP and compress the whole batch in one pass — see Compress WebP.

    Do I need to upload?

    No. All JPG processing is local. No upload, no account.
