    Product main image must be at least 1600px on the long edge and under 10MB. Compressy resizes to 1600px max and shows size before you upload.

    Can I batch my whole listing?

    What if I keep EXIF?

    Keep EXIF for product detail; strip it only if you want metadata gone. Compressy set both options per folder.
